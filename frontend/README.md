# MedServicePrice.kz Frontend

В этой папке будет находиться клиентская часть MVP веб-платформы MedServicePrice.kz.

MedServicePrice.kz — агрегатор цен на медицинские услуги в Казахстане: анализы, приёмы врачей, диагностику и другие услуги клиник. Платформа автоматически собирает актуальные прайсы из открытых источников в интернете, структурирует их и предоставляет пользователю удобный интерфейс для сравнения цен и выбора наиболее выгодного предложения.

Идея сервиса похожа на Aviasales, но для медицинских услуг: пользователь сможет быстро найти нужную услугу, сравнить цены в разных клиниках и выбрать подходящий вариант.

## Проблема

Сейчас пациенту приходится вручную обходить десятки сайтов клиник, чтобы сравнить стоимость анализа крови, приёма терапевта, УЗИ или другой медицинской услуги. Рынок непрозрачен, а цены не собраны в одном удобном месте.
